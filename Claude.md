# Modpack Scripting Rules
- Focus strictly on files in `kubejs/server_scripts/` and `kubejs/startup_scripts/`.
- Do not create extraneous files or install third-party packages.
- Platform: Minecraft 1.21.1 on NeoForge using KubeJS 6/7.
- Always use proper KubeJS recipe and event syntax for this version.


This is built for Tensura 1.21.1 neoforge, utilising legendary survival overhaul for thirst, temp and locational damage.

you should also create bridging scripts that convert the total Tensura hp to the locational parts, add temp immunity to skills and spiritual races or the slime, create a kube js script to add thirst automatically to items.
always look up the latest config and wiki docs for it
